# 4-bit CPU Design

An incremental design and implementation of a custom 4-bit CPU architecture using Logisim Evolution.

This project aims to build a complete 4-bit CPU step by step, starting from the fundamental processing unit: the ALU.

## Current Progress

### Version 0.1 - 4-bit ALU

Implemented:
- 4-bit Arithmetic Unit
- 4-bit Logic Unit
- Addition operation
- Subtraction operation
- AND operation
- OR operation
- XOR operation
- NOT operation
- Arithmetic/Logic mode selection
- Operation selection using control inputs

## Tools Used

- Logisim Evolution
