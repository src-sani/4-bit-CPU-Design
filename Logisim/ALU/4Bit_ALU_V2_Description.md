# ALU v2 Documentation

## Module Name

**Arithmetic Logic Unit (ALU) v2**

## Purpose

The ALU performs arithmetic and logical operations on two 4-bit operands. It serves as the primary computation unit of the CPU and provides the computation result along with the arithmetic carry output.

---

## Inputs

| Signal      |  Width | Description                      |
| ----------- | -----: | -------------------------------- |
| A           | 4 bits | First operand                    |
| B           | 4 bits | Second operand                   |
| ALU_Control | 3 bits | Selects the operation to perform |

---

## Outputs

| Signal    |  Width | Description                               |
| --------- | -----: | ----------------------------------------- |
| Result    | 4 bits | Result of the selected operation          |
| Carry_Out |  1 bit | Raw carry output from the arithmetic unit |

---

## ALU Control Encoding

| ALU_Control | Operation |
| ----------- | --------- |
| 000         | AND       |
| 001         | OR        |
| 010         | XOR       |
| 011         | NOT       |
| 100         | ADD       |
| 101         | SUB       |
| 110         | Reserved  |
| 111         | Reserved  |

---

## Internal Architecture

The ALU consists of three major blocks:

### 1. Arithmetic Unit

* Built using a combined Adder-Subtractor.
* Uses XOR gates to conditionally complement operand **B**.
* Addition is performed by passing operand **B** unchanged.
* Subtraction is performed using two's complement arithmetic:

  * Operand **B** is complemented.
  * The least significant carry-in is set to 1.

The Arithmetic Unit outputs:

* 4-bit arithmetic result
* Raw Carry_Out

---

### 2. Logic Unit

Performs:

* AND
* OR
* XOR
* NOT

A decoder selects the required logical operation using the lower two bits of **ALU_Control**.

---

### 3. Result Selector

A 2:1 multiplexer selects between:

* Arithmetic Unit output
* Logic Unit output

The selection is controlled by the most significant bit of **ALU_Control**.

---

## Carry Output

The ALU outputs the **raw carry** generated by the arithmetic unit.

Interpretation:

* **Addition**

  * Carry_Out = 1 → Carry generated.
  * Carry_Out = 0 → No carry.

* **Subtraction**

  * Carry_Out = 1 → No borrow occurred.
  * Carry_Out = 0 → Borrow occurred.

The ALU does not convert carry into borrow. Interpretation of this signal is handled by the CPU architecture during integration through the Flag Register and Control Unit.

---

## Design Improvements from ALU v1

* Replaced multiple control lines with a single **3-bit ALU_Control** bus.
* Encapsulated Arithmetic Unit and Logic Unit into independent modules.
* Reduced top-level wiring using buses and splitters.
* Removed carry/borrow conversion logic and exposed the raw arithmetic carry output.
* Improved readability and modularity for CPU integration.
