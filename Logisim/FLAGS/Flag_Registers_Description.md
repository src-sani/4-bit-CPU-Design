# Flag Register Module

## Description

The Flag Register stores status information generated by the ALU. It contains two flags:

- Zero Flag
- Carry Flag

The module uses flip-flops with MUX-based enable logic to either update the flags or hold the previous values.

## Inputs

- ALU Result (4-bit) – Used for zero detection.
- ALU Carry Out (1-bit) – Used for carry flag storage.
- Flag Enable – Enables updating of flag values.
- Clock – Updates the flip-flops.

## Outputs

- Zero Flag Output
- Carry Flag Output

## Working

### Carry Flag

The ALU carry output is connected to the Carry Flag flip-flop through a MUX.

- Flag Enable = 1 → Stores new carry value.
- Flag Enable = 0 → Holds previous value.

### Zero Flag

The ALU 4-bit result is checked using OR gates and a NOT gate.

Logic:

Zero Flag = NOT(B3 OR B2 OR B1 OR B0)

If the ALU output is `0000`, the Zero Flag becomes `1`.

### Enable Logic

MUX feedback is used before each flip-flop.

- Enable = 0 → Previous value is fed back (hold).
- Enable = 1 → New input is stored.
