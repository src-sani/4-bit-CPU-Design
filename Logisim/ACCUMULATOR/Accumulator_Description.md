# Accumulator Version 0.1

## Overview
Implementation of a 4-bit accumulator register used for storing ALU results during CPU operations.

## Description
The accumulator is a special-purpose register that stores intermediate results generated by the ALU and provides its stored value back to the datapath.

## Inputs
- ALU_Result[3:0]
- Clock
- ACC_Load

## Output
- ACC[3:0]

## Architecture
- Reuses the 4-bit Register module
- Stores ALU output values
- Provides stored value as an ALU input

## Operation
- When ACC_Load is enabled, the accumulator stores the ALU result on the clock edge.
- When ACC_Load is disabled, the accumulator retains its previous value.
